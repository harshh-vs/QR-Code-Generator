# QR Code Generator 🔗

A simple, fast, and free QR Code Generator that works right in your browser — no app, no sign-up, no installation needed.

## 🌐 Live Website
👉 [Click here to open the tool](https://harshh-vs.github.io/qr-generator)
*(replace with your actual link)*

## ✨ Features
- Paste any URL and instantly generate a working QR code
- Choose from 3 sizes — Small, Medium, Large
- Download the QR code as a PNG image
- Scan with any phone camera — no QR app needed
- Works on desktop and mobile browsers
- Completely free, no data is stored or tracked

## 🛠️ Built With
- HTML, CSS, JavaScript
- [qrcode-generator](https://github.com/harshh-vs/qrcode-generator) 

## 🚀 How to Use
1. Open the website link above
2. Paste any URL into the input box (must start with `https://`)
3. Click **Generate**
4. Scan the QR code with your phone camera or download it as PNG

- Quickly send a link to your phone
